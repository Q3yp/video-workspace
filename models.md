# Models

How to drive each model the workspace uses. Limits, durations and resolutions change between versions; read them from `libtv-local models "MODEL DISPLAY NAME" --schema --json`.

## Codex image generation

Asset images are generated by a Codex agent with its built-in image tool (GPT Image). It is the generating agent in `assets.md`.

Delegate through T3 `delegate_task` with provider `codex` and model `gpt-6-astra`, once per prompt file, and say that it generates the images itself with its built-in image tool. Its own web search finds the real photographs a file names better than a search run by the director, so leave the finding to it.

The image prompt rules in `assets.md` come from OpenAI's [GPT Image 2.5 prompting guide](https://developers.openai.com/api/docs/guides/image-prompting). The built-in tool takes no model, quality or size setting, so the prompt and its references are the only controls. On texture-heavy images, end the prompt with "Avoid heavily repeated texture enforcements."

## MiniMax H3

Video with in-scene sound, generated from references. In `libtv-local` the model is `Minimax H3`, and reference-to-video is `--set modeType=mixed2video`.

Convert the four-section draft with the `h3-prompt-writing` skill in full-reference mode. Reference labels are `<Picture 1>`, `<Video 1>` and `<Audio 1>`. The schema caps the prompt's length; check the converted prompt against it before generating.

In first-and-last-frame mode (`--set modeType=frames2video`), a push or dive heads for the centre of the first frame whatever place the prompt names. Put the place the camera must reach at the centre of the first frame.

## Seedance 2.x

Video with in-scene sound, generated from references. In `libtv-local` its display names start with `Seedance 2`; list the current ones with `libtv-local models --type video --json`.

It has no prompt skill: write the four sections of the shot prompt directly, under their own headings. Reference labels are `@Image1`, `@Video1` and `@Audio1`.

## MiniMax Speech

Narration from text. In `libtv-local` the model is `Minimax-speech-2.8-hd`, generated as one audio job per line with `--set scene=Text-to-Speech`.

- **Voice:** `--set voice_setting_voice_id=ID`. A voice the user picks by its Chinese display name maps to an ID through MiniMax's system voice list: https://platform.minimax.cn/docs/faq/system-voice-id
- **Pace and pitch:** `voice_setting_speed` (1.0 is normal) and `voice_setting_pitch` (0 keeps the voice's own).
- **Strength:** `voice_modify_intensity`; negative values give a stronger delivery.

The text is spoken as written, so it holds only the line itself, with no stage directions. Record each line's settings in a brief beside the recordings, so a line can be regenerated alone.
